# MERN Stack Developer Portfolio — Phase 1

A responsive React + Vite portfolio starter with creative dark/light themes.

## Requirements
- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Customize
- Replace `Your Name` in `src/components/Hero.jsx`.
- Update social profile URLs in `Navbar.jsx` and `Hero.jsx`.
- Put your CV at `public/cv.pdf` to enable the Download CV link.
- Update the portfolio content as we build the remaining sections.

## Current scope
Phase 1 starter: navigation, hero section, theme switcher, and responsive styling.
The About, Skills, Projects, Education, and Contact sections will be added in the next development step.
